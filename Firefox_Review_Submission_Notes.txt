=== REPRODUCIBLE BUILD VERIFICATION ===

Requirements:
- Docker installed and running (the build runs entirely inside a pinned node:24 Alpine image)
- Git installed

To verify the submitted package matches source code exactly:

1. Clone repository:
   git clone https://github.com/RunOnFlux/ssp-wallet.git
   cd ssp-wallet

2. Checkout the exact version being reviewed:
   git checkout v2.2.1

3. Build deterministically using Docker:
   bash scripts/deterministic-build.sh
   (the same as `yarn build:deterministic`; no local `yarn install` is needed)

4. Verify the Firefox package hash matches the submission:
   sha256sum ssp-wallet-firefox-v2.2.1.zip
   # Compare with the hash of the submitted package and with SHA256SUMS on
   # https://github.com/RunOnFlux/ssp-wallet/releases/tag/v2.2.1
   # The hashes should be identical, proving the submitted package
   # was built from the exact source code in the repository.

The deterministic build ensures:
- Same source code always produces identical packages
- Exact dependency versions from yarn.lock, each checked against its integrity hash
- No dependency install scripts run except the allowlisted ones
- Docker isolation from the host environment

See REPRODUCIBLE_BUILDS.md for complete technical details.
